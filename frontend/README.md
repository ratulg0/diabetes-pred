# GlucoCare frontend

React + TypeScript + Tailwind CSS UI prototype for the diabetes prediction project.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Screens included

- Overview dashboard with responsive statistic cards and illustrative charts.
- New assessment form with field validation and a demo result state.
- Assessment history with search, status filtering, and CSV export.
- Preferences screen with local display toggles.

## Important limitations

This is a frontend-only prototype. Assessment results are generated by an illustrative placeholder formula and are not model predictions. Charts and starting history records are sample data. No API, trained model, sensor, authentication, or persistent storage is connected. Do not use this interface for clinical decisions.

## Visual direction

Light canvas, blue typography and actions, soft borders, spacious cards, responsive navigation, keyboard-visible focus styles, and charts with labels.
